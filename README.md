# LexiCode-Compiler

A simple compiler project with lexical analysis built using Python.

## About

LexiCode is a beginner-friendly compiler project developed using Python.
It performs lexical analysis by analyzing source code and identifying
different types of tokens.

## Features

- Lexical analysis
- Token identification
- Keyword detection
- Identifier detection
- Number detection
- Operator detection
- Separator detection
- Simple web interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
